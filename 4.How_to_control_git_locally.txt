--> git branch -m master main

git status --> to see any modification previously 

then use ' git add filename' to put file or code in staging area 

Comparison of Commands
Command	What it adds	Scope
git add -A or git add --all	Untracked (new), modified, and deleted files	Entire repository, regardless of your current folder
git add .	Untracked (new), modified, and deleted files	Current folder and its subfolders only
git add -u	Modified and deleted files only (ignores new files)	Entire repository
