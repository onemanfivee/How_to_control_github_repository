this github command is use to control repository remotely

to change master to main 
use --> git branch -m master main

The first thing is creating a remote repository

 use command --> git remote add <name> <url>

e.g --> git remote add origin https://github.com/onemanfivee/How_to_control_github_repository.git

then 
to push repository to remote repository

use command --> git push -u <remote Name> <branch name>

e.g --> git push -u origin main
